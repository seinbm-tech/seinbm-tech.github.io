개인정보처리방침

시행일: 2026년 10월 28일 · 개인 운영용 애플리케이션

봉봉이 · NOVA Backup은 사용자가 직접 승인한 Google Drive 문서를 사용자 관리 PC 및 NAS에 보관하기 위한 도구입니다. 공개 웹사이트는 Google 계정 인증이나 문서 업로드 기능을 제공하지 않습니다.

1. 운영 목적과 범위

이 앱은 개인 연구 문서의 읽기 전용 백업 및 복구를 위해 설계되었습니다. 불특정 다수에게 제공하는 클라우드 저장 서비스가 아닙니다. 실제 기능 및 자동화는 사용자의 운영 장치에서 별도로 구성·검증됩니다.

2. 요청하는 Google API 권한

https://www.googleapis.com/auth/drive.readonly 범위를 사용합니다. 이 권한은 해당 Google 계정에서 접근 가능한 Drive 파일의 조회 및 다운로드를 허용할 수 있습니다. 특정 폴더만 백업하도록 지정하는 것은 OAuth 권한 자체의 제한이 아니라 로컬 프로그램 설정입니다. 이 앱은 Google Drive 문서를 수정하거나 삭제하기 위한 권한을 요청하지 않습니다.

3. 접근하는 데이터

  • 사용자가 설정한 백업 대상 폴더에 있는 파일 이름, 식별자, 수정 시각 등 파일 메타데이터
  • 백업 대상으로 선택된 Google 문서의 내보내기 결과 또는 파일 내용
  • Google OAuth 인증 과정에서 개인 기기에 저장되는 접근 및 갱신 토큰

로컬 파일과 인증 토큰은 개인 백업 수행에만 이용합니다. Google 계정 비밀번호를 이 사이트에서 요구하지 않습니다.

4. 사용 및 보관

데이터는 사용자가 관리하는 Q-Hoom PC 및 연결된 NAS에 복사·보관하도록 설계됩니다. 백업 기간과 삭제 여부는 운영자가 관리합니다. 이 공개 웹사이트나 GitHub Pages 저장소에 연구 문서 또는 OAuth 토큰을 업로드하지 않습니다.

5. 공유 및 제3자 제공

연구 문서를 광고, 판매 또는 데이터 브로커 목적으로 사용하지 않습니다. Google API 접근은 사용자가 승인한 작업을 위해서만 수행합니다. 정적 웹페이지는 GitHub Pages에서 제공되며, 페이지 접속에 관한 호스팅 측 기술적 로그는 GitHub 정책의 적용을 받을 수 있습니다.

6. 보호 조치

백업 경로와 OAuth 설정 파일은 비공개 개인 기기에서 관리하고, 운영체제의 접근 권한과 저장소 보안 설정을 적용하도록 설계합니다. 로컬 백업 암호화 여부는 장치 구성에 따라 달라지며, 모든 저장 데이터가 자동으로 암호화된다고 보장하지 않습니다.

7. 이용자의 통제와 삭제

사용자는 언제든 백업 프로그램을 중지하고 개인 PC 또는 NAS의 사본을 직접 삭제할 수 있습니다. Google 계정에서 앱 접근 권한을 철회하려면 Google 계정의 연결된 앱 설정을 사용하세요. 접근 권한을 철회해도 이미 만들어진 로컬 사본은 자동 삭제되지 않습니다.

8. 문의 및 정책 변경

개인용 도구에 관한 문의는 GitHub 저장소의 Issues로 전달할 수 있습니다. 공개 이슈에 개인정보, 토큰, 비밀번호 또는 연구 원문을 게시하지 마세요. 데이터 처리 방식이 달라지면 이 문서를 먼저 갱신합니다.
