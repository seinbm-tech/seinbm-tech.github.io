🔐

최소한의 권한

Google OAuth에서 Drive 읽기 전용 권한을 요청합니다. 업로드·수정·삭제 권한은 요청하지 않습니다.

🗂️

선택한 폴더만

Google OAuth 권한은 Drive 전체 읽기가 가능하지만 백업 프로그램은 지정한 폴더를 대상으로 설정합니다.

🛡️

사용자 소유 저장소

내보낸 데이터와 접근 토큰은 사용자가 관리하는 장치에 보관하며, 공개 GitHub 저장소에 업로드하지 않습니다.
